# Qazaq Chess ♞

Қазақ тіліндегі веб-шахмат. Компьютерге қарсы немесе бір құрылғыда екі адам болып ойнауға болады. Телефонға да бейімделген.

## Іске қосу

1. ZIP файлын ашып, `QazaqChess` папкасын шығарып ал.
2. `index.html` файлын браузерде аш. Шахмат ережелері CDN-нен жүктелетіндіктен, интернет қосулы болуы керек.
3. GitHub арқылы жариялау үшін осы папкадағы файлдарды репозиторийдің түпкі деңгейіне жүкте.
4. GitHub репозиторийінде **Settings → Pages → Deploy from a branch → main / (root) → Save** таңда. Жарияланған сілтеме Pages бөлімінде көрінеді.

## Stockfish 19 қосу (қосымша)

Жоба Stockfish-сыз да қосалқы жеңіл ботпен ойнай алады. Күшті Stockfish 19 қозғалтқышын қосқың келсе:

1. `engine` папкасына кір.
2. Ресми релизден төмендегі екі файлды жүктеп, осы папкаға сақта:
   - `stockfish-19-lite-single.js`
   - `stockfish-19-lite-single.wasm`
3. Файл атауларын өзгертпе. Екеуі бір папкада тұруы керек.
4. Екі файлды да GitHub репозиторийіне жүкте. Сайтты қайта жарияла.

Ресми файлдар: https://github.com/nmrugg/stockfish.js/releases/tag/v19.0.1

## Ескерту

- Шахмат ережелері `chess.js` 0.10.3 кітапханасымен тексеріледі.
- Stockfish файлы қосылмаған жағдайда қосалқы бот кездейсоқ/қарапайым тактикалық жүрістерді таңдайды; бұл Stockfish деңгейіндегі ойын емес.
- Бұл нұсқаны жарияламас бұрын телефон мен компьютерде тексеріп көр. Интернет байланысы керек.
- Stockfish.js GPL-3.0 лицензиясымен таратылады. Қозғалтқыш файлдарын қоссаң, олардың лицензиясын да бірге сақта.
